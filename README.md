# cutter

Optimiseur de découpe linéaire pour Linux (alternative autonome à SmartCut.Pro)

## Description
Application GTK+3 en C pour l'optimisation de découpe de barres/planches/tubes.

## Fonctionnalités prévues
- Algorithme d'optimisation First Fit Decreasing
- Interface GTK+3 avec grilles éditables
- Import/Export CSV
- Export PDF des schémas de coupe
- Gestion du trait de scie et des chutes utiles

## Compilation
```bash
make
```
